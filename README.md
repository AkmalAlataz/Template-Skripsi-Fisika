# Template Skripsi Fisika

Panduan membangun lingkungan penulisan skripsi menggunakan **LaTeX** dan **Visual Studio Code (VS Code)**, dilengkapi konfigurasi, automasi kompilasi, dan integrasi template skripsi.

Repository ini dibuat untuk membantu mahasiswa membangun workflow penulisan dokumen ilmiah yang terstruktur, efisien, dan mudah direproduksi.

## Features

- **LaTeX Environment** — konfigurasi lingkungan LaTeX untuk penulisan dokumen ilmiah.
- **VS Code Integration** — integrasi Visual Studio Code dengan ekstensi LaTeX Workshop.
- **Automated Compilation** — automasi proses kompilasi dokumen LaTeX.
- **Bibliography Management** — pengelolaan referensi menggunakan BibTeX dan Zotero.
- **Thesis Template Integration** — panduan penggunaan template skripsi.
- **Reusable Configuration** — konfigurasi yang dapat digunakan kembali untuk proyek skripsi baru.

## Prerequisites

Perangkat lunak yang diperlukan:

- [Visual Studio Code](https://code.visualstudio.com/)
- [LaTeX Distribution](https://www.latex-project.org/get/)
- [Git](https://git-scm.com/)
- [LaTeX Workshop Extension](https://marketplace.visualstudio.com/items?itemName=James-Yu.latex-workshop)

Detail instalasi dan konfigurasi akan dijelaskan pada dokumentasi repository.
